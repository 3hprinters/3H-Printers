# 3H Printers Website

Professional responsive website for 3H Printers, a Rawalpindi & Islamabad printing, branding and customization business.

## Files
- `index.html` — website structure and content
- `style.css` — responsive visual design
- `script.js` — mobile navigation and dynamic footer year
- `assets/` — place final business images and logo here

## GitHub Pages
1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select `main` and `/ (root)`.
4. Save and wait for GitHub Pages to publish the site.

## Before launch
Replace placeholder contact details/links with the official 3H Printers information and add the final logo and real product photography in `assets/`.
