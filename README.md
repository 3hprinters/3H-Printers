# 3H Printer Website

A static, responsive GitHub Pages-ready website for **3H Printer**.

## Deploy to GitHub Pages
1. Create a new GitHub repository (for example `3h-printer`).
2. Upload `index.html`, `style.css`, `script.js` and the `assets` folder.
3. Commit the files.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Select `main` and `/ (root)`, then Save.

## Before launch
- Replace placeholder portfolio/mockup artwork with 3H Printer's real product photos.
- Add the official phone / WhatsApp / email / business address.
- Connect the quote form to a form service, email backend or WhatsApp.
- Add your final logo/favicon if available.

## Notes
The site is an original 3H Printer implementation inspired by the service/category approach of printing-industry websites; it does not copy another site's branding or proprietary text/assets.
